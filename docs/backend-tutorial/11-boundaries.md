# 11 当前实现的边界，不把规划当成事实

本页帮助你读代码时避免错误假设，不是本次新增的修复清单。仅文档记录，没有修改这些业务行为。

## 已实现但有边界

| 能力 | 不能过度推断的地方 |
| --- | --- |
| 事务与索引 | SQL 提交后异步索引；不是跨 SQL/Chroma/文件原子事务，也没有可靠任务队列 |
| 账号撤销 | refresh/设备失效不自动让全部既发 access 立即失效 |
| 验证码 | random.randint；Redis 消费不随 SQL 回滚；邮件依赖清单未列 aiosmtplib |
| 资料上传 | PDF 没有 OCR；completed 在 commit 前，finish 在后；取消补偿不覆盖一切 |
| 全文搜索 | 迁移链创建后又删 FULLTEXT，运行可回退 LIKE |
| 分类排序 | `_next_sort_order` 对 max=0 有边界；reorder 的集合检查不等于严格无重复排列 |
| 回收站 | 分类恢复不还原已提升孩子/已解绑笔记；笔记永久删除不要求先软删 |
| 复习 | quality 不驱动间隔；只存最后一次 reviewed_at，不是完整打卡日志 |
| 模型 | 无 key 的哈希向量/关键词工具/字符串拼接是流程兜底，不是真离线智能模型 |
| 摘要 | 开启检索摘要后所有非空 hit 都尝试，没有“足够长才调用”的长度门槛 |
| 工具安全 | server user_id 绑定和只读过滤是边界；模型提示本身不能提供完整事务保证 |
| 幂等 | 按用户/角色防消息重放，不是所有副作用 exactly-once，不是同会话串行锁 |
| SSE 槽 | 120 秒计数 TTL 不续租，长任务/Redis 状态变化有计数边界 |
| 后台标题 | 同进程 key 串行与条件更新保护手动改名，不是通用跨进程任务协调 |
| 用量 | 供应商数据缺失时估算，种子价格不是实时账单；非完整端到端 trace |
| 健康探针 | ready 只检查 SQL/Redis，不检查全部 AI/SMTP/向量能力 |
| 角色模型 | 可独立 model 名，共用 key/endpoint；不是任意角色各用一个供应商 |

## 后续阶段，当前不要沿空入口寻找

主线到阶段 44。工具调用独立审计落库、Agent 发邮件、PPT、TTS、DeepL/Wolfram、MCP、完整聊天附件生命周期、视觉问答、黄金评测、Langfuse 等更完整观测、专门的本地模型一键切换尚不在本次已实现教学主线中。

特别注意：普通 HTTP 邮件导出已经有，不等于 Agent 发邮件工具有；`attachment_ids` 和 thinking 互斥字段已有，不等于附件上传/视觉问答有；兼容接口可配置 base_url，不等于有完整的一键 Ollama 切换产品流程。

## 哪些注释需要带着上下文读

`auth_utils.py` 顶部曾写设备管理未实现，但后面已有设备函数。旧聊天入口、历史窗口、手写工具循环已清理，相关章节和索引以当前唯一主链为准。历史阶段记录帮助理解演进，不能替代执行路径。

教程覆盖的是“当前代码定义了哪些函数、这些函数怎样连接”，不是声称所有函数都可从同一个入口到达，也不是声称所有已定义功能都经过真实外部服务验证。
